# RF-Mem 论文复现与 PersonaMem 扩展实验

## 一、研究对象

论文：Evoking User Memory: Personalizing LLM via Recollection-Familiarity Adaptive Retrieval

本目录整理 RF-Mem 相关源码及 PersonaMem 扩展实验结果。

本归档并不表示所有实验均已通过独立复现验证。

## 二、目录结构

- `original/`：从 RF-Mem Official 本地项目筛选的源码。
- `32k/`：PersonaMem 32K 候选实验结果及扩展实验共享代码。
- `128k/`：PersonaMem 128K 实验结果。
- `1m/`：PersonaMem 1M 实验结果。

128K 和 1M 目录没有单独复制完整运行环境，相关共享实现位于 `32k/`。

## 三、PersonaMem 结果

| 数据集 | 正确数 | 总数 | 准确率 |
|---|---:|---:|---:|
| 32K 候选 | 314 | 589 | 53.31% |
| 128K | 1263 | 2727 | 46.31% |
| 1M | 968 | 2674 | 36.20% |

准确率按结果 JSON 中 `score=True` 的数量除以记录总数计算。

对应文件：

- 32K 候选：`32k/metrics.json`
- 128K：`128k/metrics.json`
- 1M：`1m/metrics.json`

注意：32K 候选结果与 `questions_32k.csv` 的完整运行映射仍需进一步核实。

## 四、代码配置审计

已观察到的代码配置包括：

- 模型接口：`VLLMQwen`
- 默认模型路径：`./LLM_src/Qwen3-8B-base`
- 检索模型（run.sh）：`multi-qa-MiniLM-L6-cos-v1`
- 检索数量（run.sh）：10
- Beam width（run.sh）：3
- Fanout（run.sh）：2
- 生成温度：0.0
- 随机种子：42

`run.sh` 包含 alpha 和 tau 参数网格搜索，不能直接认定其生成了上述三组正式结果。

代码中的部分检索参数由分支内部固定设置，不能简单视为全局统一配置。

## 五、数据与环境说明

32K、128K、1M 表示数据集历史长度级别，不等同于模型实际接收的上下文窗口。

本目录未包含完整模型权重、原始大型上下文、完整依赖环境或检索缓存。

本归档属于经过筛选的研究记录，并非开箱即用的完整复现实验包。

## 六、安全与可复现性限制

- 排除 `apitokens/`。
- 排除大型原始上下文、模型缓存及运行日志。
- 已对初始归档文件进行常见密钥格式扫描，未发现匹配项。
- 尚未完成所有数据内容的隐私与发布许可审计。
- 尚未独立确认三组实验的全部运行命令、模型权重版本及配置一致性。

因此，不应直接将三组结果解释为严格公平的跨方法对照实验。
