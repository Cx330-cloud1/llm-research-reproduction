# MemGAS：论文复现与长历史记忆实验

## 一、项目简介

本目录整理了 MemGAS 原论文相关代码、本地复现代码，以及基于 PersonaMem 数据集开展的 32K、128K 和 1M 三组长历史记忆实验。

本项目旨在记录实验配置、运行流程、评价结果和复现限制，为后续方法比较与可复现性审计提供依据。

## 二、目录结构

| 目录 | 内容 |
|---|---|
| `original/` | 原论文代码及本地复现、修改脚本 |
| `32k/` | PersonaMem-32K 实验 |
| `128k/` | PersonaMem-128K 实验 |
| `1m/` | PersonaMem-1M 实验 |

## 三、PersonaMem 实验结果

| 实验版本 | 问题数量 | 正确数量 | 准确率 |
|---|---:|---:|---:|
| 32K | 589 | 270 | 45.84% |
| 128K | 2727 | 917 | 33.63% |
| 1M | 2674 | 810 | 30.29% |

以上为本地实验结果，并非原论文报告的指标。

**重要说明：** 32K、128K 和 1M 表示 PersonaMem 数据集的历史长度版本，不代表模型在单次推理中完整读取了对应长度的上下文。

## 五、实验复现说明

本仓库保留以下内容：

- 实验运行与数据处理脚本
- 记忆构建、索引和检索相关代码
- 问答评测脚本
- 小型 JSON 实验结果与审计文件

为控制仓库体积，以下内容不直接上传：

- 大规模原始数据集及中间数据
- 模型权重
- Embedding 缓存
- 大型生成日志及临时文件

完整复现需要另行准备相应数据集、模型文件和运行环境。

## 六、复现限制与注意事项

1. 本地实验结果不等同于原论文的官方结果。
2. 不同历史长度版本需要分别核实数据构建和检索流程。
3. 实验准确率不能单独证明模型具有相同规模的原生上下文处理能力。
4. 原论文复现、PersonaMem 扩展实验及预检实验应明确区分。
5. 模型配置、提示词、检索参数和评价方法仍需结合实际脚本进行审计。
